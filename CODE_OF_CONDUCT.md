# Code of Conduct

We want participation in ai-agent-audit to be safe, respectful, and
constructive.

## Expected Behavior

- Be considerate and focus criticism on ideas and code.
- Welcome people with different backgrounds and levels of experience.
- Respect privacy, responsible-disclosure boundaries, and the sensitivity of
  security research.
- Accept feedback gracefully and help maintain a productive technical record.

Harassment, discriminatory language, threats, deliberate disclosure of private
information, and publication of uncoordinated exploit details are not accepted.

## Enforcement

Report conduct concerns privately to the repository owner through the contact
method on the owner's GitHub profile. Reports will be reviewed confidentially
and may result in content removal, warnings, temporary restrictions, or a ban
from project spaces.

By participating, you agree to follow this code in project repositories,
issues, pull requests, reviews, and related community spaces.
