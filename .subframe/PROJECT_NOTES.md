## AI Analysis

_Generated by SubFrame onboarding on 2026-03-27_

**Vision:** Comprehensive security audit daemon that monitors OpenClaw AI agent installations for vulnerabilities, malicious activity, and misconfigurations — covering the OWASP Agentic Top 10 threat landscape.

**Tech Stack:**
- Python 3.10+
- SQLite (stdlib sqlite3)
- Jinja2 (HTML report templating)
- watchdog (filesystem monitoring)
- psutil (process/network monitoring)
- argparse (CLI)
- threading (concurrent monitors)
- Unix double-fork (daemon mode)

**Key Decisions:**
- **Minimal dependency footprint** (2026-03-01): Only three runtime dependencies (watchdog, psutil, jinja2) to minimize supply chain risk for a security tool. Uses stdlib urllib instead of requests, stdlib sqlite3 instead of an ORM.
- **Plugin architecture via abstract base classes** (2026-03-15): BaseMonitor and BaseSweep ABCs allow adding new security checks without modifying the engine. Monitors are callback-based (threaded, always-on), sweeps are run-and-return (periodic).
- **Centralized enrichment pipeline** (2026-03-20): All findings pass through mappings.enrich() and PrecisionTracker.calibrate() before storage, ensuring consistent MITRE ATT&CK/OWASP ASI tagging, remediation guidance, and confidence scoring across all 27 detection modules.
- **Environment profiling to skip irrelevant checks** (2026-03-22): EnvironmentProfiler detects what's installed (Docker, MCP, skills, gateway) so sweeps like docker_security or mcp_security are skipped when their targets don't exist, reducing noise and scan time.
- **Confidence calibration from triage feedback** (2026-03-27): PrecisionTracker learns from human triage (confirmed/false_positive) to adjust future confidence scores per detection rule, with a minimum sample threshold before adjustments kick in. Low-confidence findings are still stored but suppressed from alerts.
